# Configuration

- Before running the application, you need to configure the environment variables. Create a .env file in the project root and fill in the following details:

```
PORT=8080
SALT1=""
SALT2=""
NODE_ENV=dev
```

`NODE_ENV=prod` can be used for production

# Dependancies
- Run `npm i`
- `node index.js` to run the server.
